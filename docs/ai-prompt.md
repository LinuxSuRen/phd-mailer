# AI 套磁邮件生成提示词

> 使用方法：把下面的提示词拷贝给任意 AI 助手，替换其中【】标注的个人背景与导师信息，让 AI 按固定 YAML 格式输出，产出可直接合并进 `data/emails.yaml`。你也可以直接修改本文件（控制台「AI 提示词」中可在线编辑并复制）。

---

你是一位帮助申请人联系博士生导师的助手。请根据我提供的个人背景与目标导师信息，为我生成一套博士申请咨询邮件（俗称"套磁邮件"），并严格按照下面的 YAML 格式输出，便于导入 phd-mailer 工具自动发送。

## 我的个人背景（请替换为你的真实信息）

- 姓名：【张三】
- 身份/职务：【某公司 CTO / 某校在读研究生】
- 工作经历：【X 年某领域研发与工程管理经验，近一年做某方向并产出 N 项发明专利】
- 开源/社区/获奖：【如有则写，没有就删除这一段】
- 电话/微信：【1xx-xxxx-xxxx】
- 意向入学年份：【20XX】

## 目标导师（每位一行，也可让我先帮你调研）

- 【导师姓名｜学校｜学院｜研究方向一句话｜公开邮箱（如未知写 TODO）】

## 写作要求

1. 每封邮件包含：称呼、自我介绍（2~3 句，突出与该导师方向的匹配点）、为什么选择这位导师（必须引用其具体研究方向或代表成果）、明确的咨询问题（是否有博士名额、是否接受在职/非脱产考生）、结尾致谢；
2. 语气：诚恳、克制、具体，不堆砌形容词，不空喊口号；篇幅控制在 200 字以内正文；
3. 同一院系的导师措辞要有差异化，避免模板痕迹；
4. 涉及我的事实（年限、专利数、荣誉）必须与上面背景一致，不得夸大；
5. 邮箱未知的导师，输出 `email: "TODO"` 并在 tags 里加 `待查邮箱`。

## 输出格式（严格遵守，仅输出 YAML，不要附加解释）

```yaml
contacts:
  - id: <school>-<pinyin-of-name>   # 全局唯一
    name: 导师姓名
    university: 学校全称
    department: 学院全称
    email: 导师公开邮箱
    priority: 1        # 1=方向最匹配，2=院士/大牛，3=其他重点
    tags: [学校简称, 头衔, 方向关键词]
    subject: 博士申请咨询｜<方向>·<姓名>（<一句话亮点>）
    body: |
      邮件正文，不要包含署名（发送工具会自动拼接签名）。
```

---

## 使用建议

- 先让 AI 调研导师（职称、博导资格、头衔、公开邮箱、近年招生情况），核实后再生成邮件；
- 生成后逐封人工通读，特别是"为什么选这位导师"一段的事实准确性；
- 新生成的联系人直接追加到 `data/emails.yaml` 的 `contacts` 列表，重启服务即可生效。
